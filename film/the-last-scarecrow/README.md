## 落地流程

1. **定妆**：按圣经第五节，用 Gemini / Grok Imagine 出稻草人、无人机 07、阿婆、小禾、两张主场景的参考图，锁定。
2. **生成**：按分镜表逐镜图生视频，每镜 4 版挑 1，存为 `shots/S07.mp4` 等。
3. **粗剪**：运行 `./assemble.sh`，得到 `out/rough_cut.mp4`。没生成完的镜头会显示编号占位，可以随时看节奏。
4. **声音**：按圣经第七节生成 M1–M5 配乐、录阿婆的台词、做音效，混成 `audio/mix.wav` 后重跑脚本。
5. **精修**：HUD、片名、印章、匹配剪辑的过渡在 AE / DaVinci Resolve 里完成，最后统一调色。
